# 용두그린풋살장 원페이지 웹사이트

HTML · CSS · JS만 쓰는 정적 원페이지 사이트입니다. 빌드 도구나 관리자 페이지는 없습니다.

## 폴더 구조

```
index.html          전체 마크업, SEO 메타, 구조화 데이터(JSON-LD)
css/style.css       스타일(반응형). 연출 없이도 완성된 상태
js/main.js          메뉴·헤더·주소 복사 + GSAP 스크롤 연출
favicon.ico, assets/favicon.png, assets/apple-touch-icon.png   기존 사이트 파비콘
assets/images/logo.png, logo-white.png   로고 원본 / 어두운 배경용(글자만 흰색)
assets/images/      임시 이미지(“사진 준비 중” 표시) → 실제 사진으로 교체
robots.txt, sitemap.xml
```

## 로컬 미리보기

```bash
python3 -m http.server 5510
```

브라우저에서 http://localhost:5510 을 열면 됩니다.

## 디자인 원칙

- **색**: 종이색 배경(`--paper`), 잔디 초록(`--pitch`), 먹색(`--ink`)을 기본으로 씁니다. 옐로(`--accent`)는 주요 CTA와 강조에만 씁니다. 그라데이션은 히어로 사진 위 가독성용 어두운 막 하나뿐입니다.
- **구분**: 카드·그림자·글로우·블러를 쓰지 않습니다. 구획은 면 색과 가로 선(rule)으로 나눕니다. 카드 안에 카드를 넣지 않고, 한쪽에만 두꺼운 테두리를 두는 방식도 쓰지 않습니다.
- **서체 3종**: 제목은 Black Han Sans, 숫자·전화번호·요금은 Barlow Condensed, 본문·라벨·버튼은 Pretendard입니다.
- **섹션마다 다른 레이아웃**: 소개(글+세로 사진 → 사양 표), 장비 대여(설명+사진 / 2열 번호 목록), 갤러리(모자이크, 데스크톱은 가로 스크롤), 이용 안내(표+가능/금지), 예약(타임라인 → 요금·환불 표), 위치(전폭 2분할), 유의사항(4열 번호 목록), FAQ(아코디언), CTA(큰 전화번호).

## 간격 규칙

간격은 `css/style.css`의 `:root` 토큰만 씁니다. 임의의 px 값을 새로 넣지 마세요.

| 토큰 | 값 | 쓰는 곳 |
|------|----|---------|
| `--s-1` | 4px | 라벨 ↔ 값 |
| `--s-2` | 8px | 번호 ↔ 제목 ↔ 설명 |
| `--s-3` | 12px | 버튼 사이, 소제목 ↔ 목록, 사진 격자 |
| `--s-4` | 16px | 모든 표·목록 행의 상하 여백, 표 ↔ 보조 문구 |
| `--s-5` | 24px | 섹션 제목 ↔ 리드 문단, 다열 목록 좌우 |
| `--s-6` | 32px | 본문 ↔ 버튼 그룹, 블록 사이 |
| `--s-7` | 48px | 나란한 두 표·목록 사이 |
| `--space-head` | 32–56px | 섹션 제목 ↔ 본문 |
| `--space-col` | 32–88px | 2단 레이아웃 좌우 (1단이 되면 위아래는 `--space-head`) |
| `--space-group` | 56–96px | 섹션 안 큰 덩어리 사이 (예: 타임라인 → 요금표) |
| `--section-y` | 72–128px | 모든 섹션 상하 |

공통 클래스는 세 가지입니다.

- `.split`: 2단 격자
- `.actions`: 버튼 묶음
- `.block-title`: 소제목과 굵은 선

## 인터랙션 정책

GSAP 3 + ScrollTrigger(cdnjs)와 Lenis 1.3(jsDelivr)를 `index.html` 하단에서 불러옵니다. 연출은 `gsap.matchMedia()`로 환경별로 나눴습니다. 둘 중 하나라도 불러오지 못하면 기본 스크롤로 동작하고, 콘텐츠는 모두 그대로 보입니다.

**Lenis 부드러운 스크롤**
- 마우스 휠과 트랙패드 입력만 보간합니다(`lerp: 0.1`). 터치 스크롤은 기기 기본 동작을 그대로 둡니다.
- GSAP ticker로 구동하고, 스크롤할 때마다 `ScrollTrigger.update`를 호출해 고정·스크럽 연출과 같은 프레임에 맞춥니다.
- 페이지 안 링크(메뉴, TOP, 본문 바로가기)는 `lenis.scrollTo`로 이동합니다(1.2초).
  - 헤더 높이만큼의 여백은 `html`의 `scroll-padding-top`을 Lenis가 그대로 반영합니다.
  - 이동이 끝나면 키보드 포커스도 그 섹션으로 옮깁니다.
  - 주소창 해시를 갱신하되, TOP은 해시를 남기지 않습니다.
- 모바일 메뉴가 열리면 `lenis.stop()`으로 멈춥니다. 메뉴 안은 `data-lenis-prevent`로 자체 스크롤합니다.
- `prefers-reduced-motion` 사용자에게는 Lenis를 켜지 않습니다.

튕김, 떠다님, 마퀴, 카운트업, 호버 시 떠오르는 효과는 쓰지 않습니다. 버튼은 호버해도 배경색이 바뀌지 않습니다. 텍스트 링크만 호버 시 밑줄이나 색 변화가 있습니다. 키보드 포커스 테두리는 모든 버튼에 유지합니다.

- **데스크톱** (1024px 이상이고 마우스 사용 시)
  - 히어로: 사이트명이 글자 단위로 올라오며 나타나고, 문구 → 정보 띠 순으로 이어짐. 스크롤하면 사진은 천천히, 글은 빠르게 올라가며 흐려짐
  - 섹션 제목과 표·목록 행: 화면에 들어올 때 순서대로 등장(한 번만)
  - 소개 · 장비 대여 사진: 프레임 안에서 사진만 움직이는 패럴랙스
  - 갤러리: 섹션을 고정하고 세로 스크롤로 사진을 가로로 넘김
  - 예약 단계: 스크롤에 맞춰 진행선이 채워지고 1→4 번호가 차례로 켜짐
  - 오시는 길: 지도가 살짝 확대된 상태에서 제자리로 돌아옴
- **모바일 · 태블릿**: 히어로 등장, 제목 · 목록 등장만 짧게 씁니다. 고정 · 가로 스크롤 · 패럴랙스는 쓰지 않습니다.
- **`prefers-reduced-motion`**: 모든 연출을 끕니다.
- **우측 하단 바로가기**(모든 화면): 전화 · 네이버 지도 · TOP 아이콘 버튼입니다. 글자는 없고, 스크린리더용 이름(`aria-label`)만 있습니다. TOP은 스크롤을 조금 내린 뒤에 나타납니다.

## 표현 가이드

- 사용하는 표현: 그늘막이 있는 쾌적한 풋살장 / 비와 강한 햇빛 부담을 줄인 야외 풋살장
- 사용하지 않는 표현: 실내 풋살장, 실내형 구장, 밀폐형 구장

## 사진

원본 사진은 `_originals/`에 있습니다(6000×4000, 장당 6–10MB). **배포할 때 이 폴더는 올리지 마세요.**

사이트에서는 원본을 줄인 WebP와 JPG를 두 가지 크기로 씁니다. `<picture>` + `srcset`이라 브라우저가 화면 크기에 맞는 한 장만 받습니다. 첫 화면 기준으로 약 76MB에서 약 1MB로 줄었습니다.

| 원본 | 사이트 파일 | 크기 |
|------|-------------|------|
| `main-hero.JPG` | `hero-1280 / hero-2400` | 히어로 |
| `about_1.JPG` | `about-800 / about-1400` | 구장 소개 |
| `rental.jpg` | `rental-800 / rental-1400` | 장비 대여 |
| `main-hero.JPG` | `gallery-pitch-800 / -1600` | 갤러리 · 구장 전경(큰 칸) |
| `gallery-02.JPG` | `gallery-walkway-*` | 구장 옆 통로 |
| `gallery-03.JPG` | `gallery-entrance-*` | 입구 |
| `gallery-04.jpg` | `gallery-lounge-*` | 대기실 |
| `gallery-06.jpg` | `gallery-restroom-*` | 화장실 |
| `gallery-05.jpg` | `gallery-parking-*` | 주차장 (마지막, 모바일에서 가로 전체) |
| `main-hero.JPG` | `og-image.jpg` (1200×630) | 카카오톡 · SNS 공유 썸네일 |

각 파일은 `.webp`와 `.jpg`가 한 쌍입니다.

- `about_1.JPG`와 `gallery-01.JPG`는 같은 파일이라, `gallery-01`은 쓰지 않았습니다.
- 파일명은 모두 소문자입니다. 리눅스 서버는 `.JPG`와 `.jpg`를 다른 파일로 봅니다.

**사진을 새로 넣을 때**는 `_originals/`에 원본을 두고, 위 표의 이름과 크기(긴 변 기준 800/1400/1600/2400px, WebP q74 · JPG q78)로 변환해 주세요.
